### 🛰️ GeoST-Net — Spatiotemporal Forecasting Architecture
> *ISRO Bharatiya Antariksh Hackathon · National Finalist, Top 10*

Dual-encoder architecture that fuses static spatial tensors (Conv3D) with dynamic temporal tensors (ConvLSTM) through a Cross-Attention Transformer. Includes Cellular Automata for wildfire spread simulation. Validated on MODIS, VIIRS, NASA FIRMS data.

`PyTorch` `Conv3D` `ConvLSTM` `Cross-Attention Transformer` `Cellular Automata` `Google Earth Engine`

[![Repo](https://img.shields.io/badge/GitHub-ISRO__FINAL-181717?style=flat-square&logo=github)](https://github.com/DZDasherKTB/ISRO_FINAL)

---

### 🧬 Foundational ML/DL — From Scratch
> *No high-level APIs. First principles only.*

Rebuilt the entire deep learning stack from mathematical ground up using raw PyTorch tensors and NumPy — not `model.fit()`, actual gradient engines, attention mechanisms, and inference pipelines.

- **GenAI/CV**: Stable Diffusion, StyleGAN, U-Net, DeepLab V3+, YOLO, R-CNN
- **NLP**: BERT, GPT, Transformers (full attention block)
- **Classical ML**: XGBoost, Random Forest, SVM, LSTM/GRU, RecSys (NumPy only)
- **Optimization**: Custom backprop engine · Accelerated inference `16s → 0.8s/iter` on single GPU
